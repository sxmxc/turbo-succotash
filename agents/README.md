# Agent continuity

Start with [handoff](handoff.md) and [tasks](tasks.md), then [context](context.md) and relevant [decisions](decisions.md). Read actual source and the design for the task. Root [AGENTS.md](../AGENTS.md) defines working conventions.

Update tasks and replace the handoff at a meaningful checkpoint. Add durable decisions only when a choice or rationale changes. Keep exact verification evidence in [VERIFICATION](../docs/VERIFICATION.md); link rather than duplicating logs. Never put secrets or private user data here.
