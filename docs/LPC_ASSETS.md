# Initial LPC character selection

Source: Universal LPC Character Generator, commit `d44ea7d6904891aab8627b80ff4de1560d63bdff`. The authoritative import record is [manifest.json](../apps/web/public/assets/lpc/manifest.json): each file has its original path, SHA-256, dimensions, frame layout and complete upstream credit row. Original PNG bytes are served unchanged from `/assets/lpc/`; no generator code or dependency is imported.

Five compatible adult male-base layers: body, separate human head, pants, long-sleeve shirt and shorthawk hair. This small catalog is an implementation starting point, not a restriction on future avatar choices. Each selected PNG was inspected individually: 576×256, nine columns and four rows of 64×64 frames. Rows are north, west, south, east. Column 0 is standing; columns 1–8 cycle at 8 fps. These are split walk sheets, not the legacy universal sheet with walking at rows 8–11. Other upstream layouts must be inspected before adding assets.

All layers share one elapsed-time clock, direction and foot position. Each asset carries its own frame and anchor metadata. Native foot anchor `(32,62)` follows the inspected body's standing alpha bounds (bottom exclusive 62); walking bob is authored into frames. Display scale is independently 1 world unit per source pixel. A provisional 20×10 world-unit collision footprint extends left 10 and up 10 from the feet; it is metadata for future movement, not active collision. Phaser nearest-neighbor rendering and CSS pixelated canvas scaling preserve hard pixel edges; responsive FIT can have uneven pixel widths at fractional viewport scales.

`appearance.ts` contains typed appearance IDs and the small compatible catalog. Vue owns local shirt tint/direction/walking controls, Phaser owns image layers. Walking previews in place; accounts, gameplay movement and persistence remain unimplemented. A failed asset load displays an explicit reload message instead of scene-ready status.

All five imported files offer CC-BY-SA 3.0; this integration selects that common license. Per-file alternative licenses and original contributor/source details are preserved in the manifest and credits CSV. Runtime composition and clothing tints are the only artwork modifications, and those artwork adaptations are also offered under CC-BY-SA 3.0. A visible footer link opens keyboard-accessible `/credits.html`, including license and source links and unchanged downloadable PNGs. Asset licensing does not change the project's software release policy.

To add a selection: inspect the actual PNG grid and compatible base, preserve its per-file credits and license choice, record a pinned revision/hash and anchor/layout, then verify all four directions and standing transitions. Do not assume another sheet has this grid or coordinate origin. Full editor and server-validated saved appearance remain later work.
